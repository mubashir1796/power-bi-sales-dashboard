# Sales Performance Dashboard 2026

## Overview

**Sales Performance Dashboard 2026** is an interactive Power BI report for exploring sales performance across products, product categories, customers, countries, and order dates. It brings key sales indicators and visual summaries into one place, allowing users to review performance and focus on selected segments.

## Dashboard Features

- **KPI cards:** Summary indicators for order IDs, customer IDs, and total sales.
- **Sales by Products:** A bar chart comparing sales across products, sorted from highest to lowest sales.
- **Sales by Category:** A donut chart showing the distribution of sales across product categories.
- **Sales Trend Over Time:** A line chart using the order-date hierarchy to explore sales over time.
- **Interactive filters:** Slicers for country, product category, and order date help users focus on a particular segment or time period.

The slicers and charts are intended to work together, making it easier to explore how the displayed results change when filters are applied.

## Tools

- **Microsoft Power BI Desktop** — report creation and data visualization

## How to Use

1. Download `My Power BI Sales Dashboard.pbix` from the repository.
2. Open the file in **Power BI Desktop**.
3. Use the country, category, and order-date slicers to filter the report.
4. Select chart elements to explore the data and compare the resulting views.

## Questions to Explore

- Which products have the highest sales?
- How is sales performance distributed across product categories?
- How does sales performance change over time?
- How do sales patterns vary by country, category, or date range?

## Notes

This dashboard is intended for descriptive analysis and interactive exploration. It can help identify patterns in the displayed data, but the visuals alone do not explain why a trend occurred or establish causation. Any business recommendations should be based on reviewing the results and understanding the data behind them.
